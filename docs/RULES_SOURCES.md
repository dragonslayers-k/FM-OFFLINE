# FM1 규칙 원본 및 구현 검증 기준

## 우선 적용 원본

1. 사용자가 제공한 `Manual.zip` — 판타지 마스터즈 게임 설명 및 규칙 문서(이 프로젝트의 우선 기준).
2. `FM1-CardData-v1.0.0.zip` — 카드 ID, 텍스트, 카드 유형, 능력치 및 이미지 참조 확인용 데이터팩. 데이터팩이 존재한다고 카드별 비용·효과가 검증된 것은 아니다.
3. FM LUNATIC (`https://fmlunatic.com/cardlist`) — 카드 분류·표기 대조를 위한 보조 카드 아카이브. 규칙 원본을 대체하지 않는다.
4. FAN-MADE MASTERS / 공개 커뮤니티 자료 — 카드 및 UI 대조용 보조 자료. 규칙을 임의로 가져와 FM1에 적용하지 않는다.

매뉴얼과 카드 원본의 내용이 충돌할 경우 FM1 매뉴얼의 규칙 문구를 우선하고, 에디션/시기 차이가 확인되면 출처와 판정 근거를 기록한다.

## Manual.zip에서 확인한 핵심 규칙

### 카드와 필드
- 카드 유형은 지형, 유닛, 아이템, 마법, 인챈트로 구분한다.
- 덱은 50장이고, 최소 한 장의 지형을 포함한다.
- 보통 같은 카드는 최대 4장까지 넣을 수 있으며 스페셜·유니크·업그레이드 카드는 1장 또는 2장 제한이 있을 수 있다.
- LP는 매 준비턴 1씩 누적되며 지형 배치 권한을 나타낸다. 지형 필드는 최대 10장이다. 지형 배치는 LP를 사용하며 소울을 지불하지 않는다.
- 각 지형은 매 준비단계에서 속성 소울을 생성한다.
- 유닛 필드에 배치할 수 있는 수는 지형에서 생성된 소울 수에 의해 제한된다.

### 소울 코스트
- 소환 조건의 무속성 구슬은 최초 소환 시에는 어떤 속성의 소울로도 지불할 수 있다.
- 무속성 구슬을 가진 유닛은 이후 매 준비단계마다 그 수량만큼 유지비를 지불한다.
- 유지비가 부족하면 부족한 소울 수만큼 서고 카드를 파괴한다.
- 소울 코스트 처리는 카드 드로우보다 먼저 일어난다.
- 지형 파괴 등으로 다음 준비단계에 생성 소울이 줄어들면 부족분을 서고에서 파괴한다.

### 준비와 전투
- 공격자 준비 → 방어자 준비 → 전투 순서로 진행한다.
- 각 준비 단계에서 핸드를 6장까지 채운다. 핸드를 채울 수 없는 플레이어는 패배하며 양측이 동시에 소진되면 공격자가 패배한다.
- 공격자의 공격이 방어자보다 먼저 진행된다.
- 마법과 유닛이 만나는 상황에서는 마법이 먼저 발동한다.
- 방어할 카드가 없는 직접 공격은 상대 서고를 공격한다.
- 직접 공격으로 파괴하는 서고 카드 수는 공격 유닛의 소환 소울 수(유색과 무속성 포함)다. AP 수치가 아니다.
- 리셔플은 기본적으로 첫 4턴 동안 턴당 1회 가능하다. 핸드를 덱에 되돌려 섞고 한 장을 소각한 뒤 6장을 다시 받으며, 해당 준비 단계에서 카드를 배치한 뒤에는 사용할 수 없다(옵션룰에 따른 제한 차이는 별도 처리).

### 코인과 능력치
- `C3`은 코인 3개, `2C3`은 3개 코인의 앞면 수에 2를 곱하는 표기다. 부호가 없는 식은 계산 결과로 해당 능력치를 설정하고, `+2C3`은 계산 결과를 기존 능력치에 더하며, `-C3`은 빼고, `xC3`은 곱한다.
- AP·DP·HP는 각각 독립된 능력치이며, 같은 코인 결과를 AP/DP/HP에 공유할 수 있다.
- 코인 곱셈 결과가 0이면 HP도 0이 되어 유닛이 소멸할 수 있다.
- DP는 음수가 될 수 있다.
- `*`는 능력치의 증감 모두 금지, `△`는 감소 금지·증가 허용, `▽`는 증가 금지·감소 허용으로 해석한다. HP에 * 또는 △가 붙은 경우 매뉴얼 설명상 해당 유닛은 소멸하지 않는다.

### 특수 공격 기술
매뉴얼 `specialability.htm`에 기재된 기술(방어무시, 치명, 관통, 약화, 석화, 흡혈, 노화, 돌진, 야수조련, 용맹, 재생, 광분, 연속, 공포, 매료, 봉쇄, 마법봉쇄, 무기뺏기, 복제, 방패파괴, 저주, 방어이용, 조롱, 혼란, 은폐, 방어전환)의 정의를 개별 기술 규칙으로 취급한다. 문자열 유사도나 임의의 일반 효과 그룹으로 대체하지 않는다.

## 원본 데이터 검증 현황 (2026-11-01 기준)

최신 카드팩 감사에서 15,350개 카드 레코드와 15,350개 이미지가 확인되었고, ID 누락·중복·이미지 참조 누락은 0건이었다. 이 결과는 파일 구조와 참조 무결성 확인이지, 카드별 비용·효과의 정확성 또는 게임 내 완전한 작동 검증을 의미하지 않는다.

비용 구슬은 원본 이미지에서 카드별로 검증해야 한다. JSON의 `cost` 필드 존재나 `costKnown` 값만으로 비용을 검증된 것으로 간주하지 않는다. 빈 비용 객체를 무료 비용으로 자동 처리해서는 안 된다. 명시적인 0 비용은 `{neutral:0}`처럼 실제 비용 필드가 있어야 한다. 지형 배치는 LP로 처리하며 별도 소울 설치비를 요구하지 않는다. 지형 소울 생산과 유닛의 무속성 유지비는 별도 규칙이다.

카드별 효과 구현 시 다음을 기록한다.

- 카드 ID와 원문 텍스트
- 카드 분류 및 원본 조건/구슬
- 발동 주체와 발동 시점
- 대상 및 선택 조건
- 능력치 변경 및 소울/서고/필드 변화
- 지속시간과 종료 시점
- 예외 조건 및 상호작용
- 매뉴얼 근거, 자동 테스트, 수동 확인 여부

## 현재 구현과 검증 경계

- 현재 Android 앱은 카드 DB를 APK에 포함하지 않고 외부 ZIP에서 가져오는 구조다.
- 최신 CI는 카드팩을 매 APK 빌드마다 다운로드하지 않도록 분리한다.
- 규칙 테스트는 매뉴얼에 맞는 자동 테스트부터 통과해야 한다. 테스트 통과는 원작 전체 규칙·카드 효과가 완성되었다는 뜻이 아니다.
- 카드별 비용, 모든 마법 효과, 인챈트의 대상/지속시간, AI 전략, 전투 슬롯별 전체 예외를 추가 검증해야 한다.

## 매뉴얼 내부 규칙 충돌 메모

`cardtype.htm`과 `gamerule.htm` 앞부분은 누적 LP 수만큼 지형을 배치할 수 있다고 설명하지만, `gamerule.htm`의 세부 준비단계 안내는 "한 턴에 1장"이라고 적고 있다. 서로 충돌하는 문구이므로 현재 엔진은 세부 절차의 1턴 1장 제한을 유지하되, 다른 원본 화면/판본 자료로 확인하기 전까지 확정 규칙으로 단정하지 않는다. 최대 10장 제한과 LP 소비는 공통으로 적용한다.


비용 파서 검증 규칙: 실제 비용 객체에 속성 키가 하나 이상 있어야 비용 확인으로 인정한다. `costKnown:true`와 빈 `cost:{ }` 조합은 무료 비용으로 취급하지 않는다. 이미지에서 확인된 무료 비용은 `{forest:0}` 등 명시적인 0 구슬로 저장한다.

### 사용 제한 및 용어
- NamuWiki는 커뮤니티 자료이며 공식 `Manual.zip`보다 우선하지 않는다. 카드 페이지의 개별 설명도 DB29 원문 ID/TextBase/TextExtra와 대조 전에는 비실행 참고자료다.
- 속성 문서는 7개 색상 속성을 자세히 나누지만, 메인 문서는 대격변 이후 이벤트/레전드 보라색을 무속성으로 독립시켜 8속성으로 설명한다. Gamechosun 2002의 7속성 표현은 초기 판본의 역사 맥락으로만 보존한다.
- `attribute`, `race`, `affiliation`, `card_type`, 유닛 `ability`는 독립 항목이다. 앱의 기존 `faction` 키는 속성 호환 필드다.
- NamuWiki 3.6 목록, 속성별 분류 페이지, DB29 전체 카드 목록은 합치거나 서로 덮어쓰지 않는다. 카드명·표기 차이만으로 ID를 병합하지 않는다.
- Inven 커뮤니티 자료는 코스튬체인지의 일곱 지정 아이템 이름 및 에카마엘 용어를 보조 대조한다. DB29 TextExtra가 명시한 대상의 '아이템 미장착' 조건은 커뮤니티 게시글이 생략하더라도 유지한다.
- 개인 사이트 자료는 게시 시기·판본을 기록하고, 카드 원문/공식 매뉴얼을 대체하지 않는다. 접근 불가 자료는 내용 미확인으로 기록한다.

세부 인덱스 및 카드별 대조 원칙은 `docs/EXTERNAL_FM1_REFERENCE_GUIDE.md`를 참조한다.

## 소환 프로필 및 추가 분류 페이지 (2026-11-05)
- DB29의 에카마엘 프로필은 7장(키뇨엘, 라드비엘, 쿠두루스엘, 피드엘, 올피리엘, 산치엘, 마이엘)으로 원문에서 확인됐다. 기존 8행 중 모래의형상화는 턴 자릿수/존 카운트 소환 공식으로 분리한다.
- 에카마엘 조건은 1~3챕터/동일 레벨/동일 속성 무작위, 랭크 포함, 이벤트 등급 제외, 일부 제외 카드 존재 및 지형 홀짝 능력치 보너스. 후보 풀과 제외 ID는 pending.
- 모래의형상화(9010731883)는 턴 자릿수 소울 비용과 소각장·핸드·백필드 카운트 기반 능력치 산식을 가진 별도 프로필이며, 엔진 테스트 전까지 실행 금지.
- Inven 2017 지형 최대 5장 언급, NamuWiki 카드 분류·개별 페이지, 금속 아이템의 생명의물약 분류는 커뮤니티 보조 출처일 뿐 공식 매뉴얼/DB29 원문을 대체하지 않는다.
