### 에카마엘 7개 유닛
키뇨엘 10102025324, 라드비엘 10102025325, 쿠두루스엘 10102025326, 피드엘 10102025327, 올피리엘 10102025328, 산치엘 10102025329, 마이엘 10102025330.
공통 원문은 1~3챕터·동일 레벨·동일 속성 유닛을 무작위 구성하며 랭크 포함·이벤트 등급 제외·일부 제외 카드가 있다고 한다. 아군 에카마엘 지형 수가 홀수면 AP+1, 짝수면 HP+1.

### 모래의형상화 9010731883
대지 지형 1장 파괴 후 속박 2턴의 모래형상 유닛 1개 소환. 야수·골렘, 돌진공격. 유소울=턴 일의자리, 무소울=십의자리, AP=소각장 유닛 수, DP=핸드 유닛 수, HP=백필드 지형 수, 최대 레벨 10.
미확인: 턴 번호 규칙, count snapshot 시점, 소유·유형 범위, 레벨 상한의 구체 적용, 슬롯/지형 파괴 실패 및 속박 만료 순서.

## 공통 엔진 게이트
- 각 profile rule에 원본 card ID와 TextBase/TextExtra, trigger/condition/target/cost/formula/duration/failure/stacking을 연결한다.
- count snapshot, round/floor, 0값, max level, slot, ownership, failure path를 전부 테스트한다.
- 이 문서의 계산 규칙은 source-text structured 상태이며 executable 승인 근거가 아니다. T sidecar의 engine_verified=true와 focused regression 결과가 나오기 전까지 플레이/실행을 차단한다.
- 커뮤니티의 에카마엘 최대 5 언급은 보조 자료로만 사용한다.
